# جُمان — صمّم بيتك بالـ3D

موقع متكامل لتصميم البيوت بالثلاثي الأبعاد. تسحب الموبيليا وتذبها بالغرفة، تدوّرها، تغيّر لونها، وتحفظ تصميمك.

- **الواجهة:** React 18 + Vite + React Three Fiber (three.js)
- **الباك إند:** Node.js + Express 5 + JWT
- **قاعدة البيانات:** PostgreSQL

## التشغيل لأول مرة

1. **حط باسورد PostgreSQL:** افتح `server/.env` وبدّل `YOUR_PASSWORD` بباسورد مستخدم `postgres` (اللي حطيته يوم نصبت PostgreSQL):
   ```
   DATABASE_URL=postgres://postgres:الباسورد_مالتك@localhost:5432/juman
   ```
2. **نصّب الحزم:**
   ```bash
   npm run install:all
   ```
3. **جهّز قاعدة البيانات** (تخلق القاعدة `juman` والجداول وتضيف ١٩ منتج):
   ```bash
   npm run db:setup
   ```
4. **شغّل الموقع:**
   ```bash
   npm run dev
   ```
   افتح http://localhost:5173

### نسخة الإنتاج
```bash
npm run build   # يبني الواجهة بمجلد client/dist
npm start       # السيرفر يقدّم الموقع والـ API سوا على http://localhost:4000
```

## شنو موجود

| الصفحة | الرابط |
|---|---|
| الرئيسية: مشهد 3D تنزل بيه القطع وحدة وحدة، والأقسام، وآراء الزباين، وفورم التواصل | `/` |
| الموبيليا: فلترة حسب القسم وبحث، وصورة كل قطعة مرسومة 3D حقيقي | `/catalog` |

### الاستوديو: السحب والإفلات
- **من القائمة للغرفة:** القطعة تطلع بالـ3D تحت الماوس، تتمايل وية الحركة، وتوگع وتنط شوية من تذبها.
- **التصادم:** القطع ما تدخل ببعض (فحص SAT للمستطيلات المدوّرة). إذا ذبيتها بمكان محجوز، تنزاح وحدها لأقرب مكان فارغ.
- **الالتصاق:** بالشبكة (٥ سم)، وبالحيطان من تقرب منها.
- **الأغراض الصغيرة** (الفانوس، المزهرية، السندانة) تنحط فوگ الميزات والكومودينو، ومن تحرك الميز تتحرك وياه.
- **الزولية** تنفرش جوة الموبيليا وما تتصادم وياها.
- **شريط قياس** يبين المسافة لأقرب حايطين وانت ساحب القطعة.
- **الحيطان** اللي بينك وبين الغرفة تنزل وحدها حتى تشوف الغرفة.
- **وضع الليل:** الفوانيس تشعل وتضوي الغرفة.
- **التحكم:** تراجع ورجوع (Ctrl+Z / Ctrl+Y)، تدوير بـ Q و E أو بعجلة الماوس وانت ساحب، تكرار بـ Ctrl+D، وشيل بـ Delete.
- **الحفظ:** المسودة تنحفظ تلقائياً بالمتصفح. زر الحفظ يخزن التصميم وصورته بقاعدة البيانات، وزر الكاميرا ينزّل صورة بدقة عالية.

### محرر المخطط (تصميم البيت على كيفك)
- **حسب عدد الغرف:** تختار عدد غرف النوم (١-٤) والحمامات (١-٣)، وإذا تريد ديوانية أو مكتب، وجُمان يرسم المخطط ويا الممر والأبواب والشبابيك.
- **زر "عدّل المخطط":** يفتح المخطط من فوگ، وبيه تگدر:
  - تسحب الغرفة حتى تحركها، والأثاث اللي بيها يتحرك وياها.
  - تغيّر قياس الغرفة من النقاط الذهبية، أو بأزرار − و+.
  - تضيف غرفة بالنوع اللي تختاره، وتجيها باب وشباك تلقائياً.
  - تحذف غرفة، أو تغيّر اسمها ونوعها.
  - تحط **باب** أو **شباك** أو **باب رئيسي** بضغطة على أي حايط، وتسحبه على طول الحايط، وتغيّر عرضه وجهة فتحته.
- **الحماية:** الغرف تلزگ ببعضها وما تتداخل. الأبواب والشبابيك تنحفظ ويا التصميم بقاعدة البيانات، وكلشي ينتراجع عنه.

### بيت كامل
- **مخططات جاهزة:** غرفة وحدة بقياس تتحكم بيه، شقة غرفتين (٥ غرف)، وبيت عراقي كامل (٨ غرف، بيها ديوانية وممر).
- **التأثيث التلقائي:** كل غرفة تتأثث حسب نوعها (هول، مطبخ، حمام، غرفة نوم...)، والأغراض الصغيرة تنحط فوگ الميزات.
- **الحيطان:** تنبني تلقائياً، بأبواب بين الغرف وشبابيك على الحيطان الخارجية وباب رئيسي. كل غرفة إلها لون حيطان وأرضية.
- **وضع الحيطان:** تلقائي، أو نازلة، أو كاملة. بالمنظر من فوگ، الحيطان الداخلية تنزل للنص حتى يبين المخطط.
- **القطع بالغرف:** كل قطعة تبقى جوة غرفتها وما تخترق الحيطان، وشريط القياس يحسب المسافة لحيطان الغرفة اللي هي بيها.

### السلة والطلبات
- **الإضافة للسلة:** من كارت المنتج، أو من صفحته، أو **اطلب كل قطع التصميم** بضغطة وحدة من الاستوديو.
- **الطلب:** صفحة السلة بيها كل المحافظات، والتوصيل مجاني ببغداد، والدفع عند الاستلام. السعر يتحسب بالسيرفر من قاعدة البيانات.
- **طلباتي:** الطلبات تبين بصفحة تصاميمي إذا مسجل دخول.

### المجسمات
- **٤٣ قطعة حقيقية ممسوحة 3D** من [Poly Haven](https://polyhaven.com) (رخصة CC0، مجانية حتى للاستعمال التجاري). كل قطعة ويا صورتها الحقيقية، وقياساتها مقاسة من المجسّم نفسه. الملفات موجودة بـ `client/public/models`.
- **١٢ زولية بنقشات مولّدة بالكود** (`client/src/three/rugs.js`): تبريزي، كليم، مغربية، مودرن، مدورة، مدّة ممر، بساط بدوي، فرو، أطفال، سجادة صلاة، ودواسة حمام. تختار النقشة بـ `model_key` مثل `rug:kilim`.
- **٢٩ قطعة مبنية بالكود:** المطبخ والحمام والأجهزة، مثل المبردة وصوبة علاء الدين والپانكة اللي تدور.

حتى تنزّل المجسمات الحقيقية من جديد، أو تضيف غيرها:
```bash
cd tools && npm install
npm run fetch-models        # ينزل الناقص بس، ويضغطه لـ GLB ويقيس أبعاده
cd .. && npm run db:setup   # يضيف المنتجات لقاعدة البيانات
```
القائمة موجودة بـ `server/src/db/realProducts.js`. تضيف أي `ph` (اسم المجسّم بـ Poly Haven)، وتسمّيه بالعراقي، وتحط سعره.

المجسمات المبنية بالكود ما تحتاج ملفات `.glb`. خامات الخشب والقماش والباركيه والمرمر ونقشة الزولية كلها مولّدة بالكود (PBR). الإضاءة من بيئة Lightformers، يعني تشتغل بدون إنترنت. بالجودة العالية أكو ظلال ناعمة و AO (N8AO).

## الـ API

| | |
|---|---|
| `GET /api/health` | حالة السيرفر وقاعدة البيانات |
| `GET /api/categories` | الأقسام وعدد المنتجات |
| `GET /api/products?category=&q=&featured=1` | المنتجات |
| `GET /api/products/:slug` | منتج وحدة ويا منتجات مشابهة |
| `POST /api/auth/register` و `POST /api/auth/login` و `GET /api/auth/me` | الحسابات (JWT) |
| `GET/POST /api/designs` و `GET/PUT/DELETE /api/designs/:id` | التصاميم (لازم تسجيل دخول) |
| `POST /api/contact` | رسائل فورم التواصل |
| `GET /api/orders/governorates` | المحافظات وكلفة التوصيل |
| `POST /api/orders` و `GET /api/orders` | الطلبات (السعر يتحسب بالسيرفر) |

## هيكل المشروع
```
server/src
  index.js            السيرفر
  routes/             auth, catalog, designs, contact
  db/schema.sql       الجداول
  db/seedData.js      الأقسام والمنتجات (القياسات بالمتر)
  db/setup.js         ينشئ القاعدة والجداول ويضيف البيانات
client/src
  pages/              صفحات الموقع
  studio/             الاستوديو: store, placement (التصادم), DragController, Item (الحركة الفيزيائية)
  three/models/       المجسمات
  three/textures.js   الخامات المولّدة
  three/thumbnails.jsx  صور المنتجات 3D (رندر واحد مشترك)
```

## إضافة منتج جديد
**منتج حقيقي ممسوح:** شوف قسم المجسمات فوگ.

**منتج مبني بالكود:**
1. أضف المنتج بـ `server/src/db/seedData.js`، ويا `model_key` والقياسات `dims`.
2. إذا المجسم جديد، اكتبه بـ `client/src/three/models/` وسجّله بـ `MODELS` بملف `index.jsx`.
3. شغّل `npm run db:setup`.
